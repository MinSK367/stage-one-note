# 1단계 전용노트

제4회 천국고시 예상문제 2~7쪽 기반 계시록 1~7장 암기 사이트입니다.

- 제목 8문항, 단답형 45절(86빈칸), 서술형 24절
- 진척도는 한 번 이상 맞힌 답안 수를 기준으로 계산합니다. 제출 점수는 해당 회차의 입력칸을 같은 비중으로 채점합니다.
- 학습 기록은 현재 브라우저에 저장됩니다.

GitHub Pages에서 main 브랜치의 /(root)를 게시합니다. 로컬에서 index.html을 열어 사용할 수 있습니다. 검증은 Node.js에서 `node test.cjs`를 실행합니다. 기존 RV-M 본문 파일 경로를 첫 인자로 넘기면 구절별 본문 대조도 실행합니다.
